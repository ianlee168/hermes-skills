# DNS 解析陷阱 — 50.1

## 症状

- `ping 50.1` → 能通（ping 通 50.0.0.1）
- `curl http://50.1:6700/api/envs` → 超时（端口不通）
- `curl http://192.168.50.1:6700/api/envs` → **正常**（返回 401 需要认证）

## 根因

`50.1` 的 DNS 解析在不同工具/上下文中不一致：
- `ping 50.1` → 解析到 `50.0.0.1`（能通）
- `50.1` 可能被 DNS 解析到不同的 IP

## 规则

**对青龙面板，始终用 `192.168.50.1` 而非 `50.1`。**

这是已验证的：`curl -v http://192.168.50.1:6700/api/envs` 成功返回 401（需要认证），确认端口可达。
