# v4.12.0 Composer Webpack Bug Fix & Upgrade Guide

## Status (2026-05-29)

**NodeBB v4.12.0 (2026-05-27) has fixed the topicThumbs.js composer webpack bug.**

The fix was a refactoring commit (`16c43a4`): "use hooks to update thumb counts" —
the old `require(['composer'])` AMD call in `topicThumbs.js` was replaced with
a hook-based pattern that doesn't need the composer module alias in webpack config.

## GitHub Issue #14296

- **Status**: Closed
- **Fix**: Refactored `topicThumbs.js` to use hooks instead of `require(['composer'])`
- **Affected versions**: All 4.x and earlier (v4.10.3, v4.11.0, v4.11.3)
- **Fixed in**: v4.12.0+

## Upgrade from 4.11.x to 4.12.0+

```bash
docker pull ghcr.io/nodebb/nodebb:4.12.0
cd /mnt/user/appdata/nodebb
sed -i 's|image: ghcr.io/nodebb/nodebb:.*|image: ghcr.io/nodebb/nodebb:4.12.0|' docker-compose.yml
docker compose up -d
sleep 90
curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:4567/login
```

## Clean Install

```bash
cd /mnt/user/appdata/nodebb && docker compose down -v
# edit docker-compose.yml: image: ghcr.io/nodebb/nodebb:4.12.0
docker compose up -d
# Complete web installer at http://192.168.50.1:4567
```
